# 📝 Flask ToDo

Домашнє завдання №6 (Hillel): невеликий застосунок для списку задач на Flask.
Задачі зберігаються в JSON-файлі, тож після перезапуску вони не зникають.

## Можливості

- **Головна сторінка** з привітанням і лічильниками задач за статусами. Лічильник клікабельний і відкриває список із цим фільтром.
- **Список задач** у вигляді карток, з пагінацією по 9 задач на сторінку.
- **Фільтр за статусом**: «Нова», «В процесі», «Виконана».
- **Сортування за датою створення**: спочатку нові або спочатку старі.
- **Сторінка задачі** з повною назвою, статусом і датою створення.
- **Додавання й редагування** через одну спільну форму з перевіркою полів.
- **Видалення** з підтвердженням.
- Фільтр, сортування і сторінка не губляться при переході до задачі, редагуванні чи видаленні.

## Маршрути

| Маршрут | Методи | Що робить |
|---|---|---|
| `/` | GET | Головна сторінка зі статистикою |
| `/tasks` | GET | Список задач. Параметри: `?status=new\|in progress\|done`, `?sort=oldest`, `?page=N` |
| `/tasks/<id>` | GET | Сторінка задачі |
| `/tasks/add` | GET, POST | Форма додавання задачі |
| `/tasks/<id>/edit` | GET, POST | Форма редагування задачі |
| `/tasks/<id>/delete` | POST | Видалення задачі |

## Запуск

Потрібен Python 3.10 або новіший.

```bash
# 1. Створити й активувати віртуальне оточення
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 2. Встановити залежності
pip install -r requirements.txt

# 3. Запустити
python app.py
```

Застосунок відкриється на **http://127.0.0.1:8000/**.

> Застосунок працює на порту 8000, бо на macOS стандартний для Flask порт 5000 зайнятий AirPlay.
> Інший порт задається в `app.py`, у рядку `app.run(debug=True, port=8000)`.

## Формат даних

Задачі зберігаються в `data/tasks.json`:

```json
[
    {
        "id": 1,
        "title": "Зробити домашку з Flask",
        "status": "in progress",
        "created_at": "2026-11-04T10:15:00"
    }
]
```

- `status` може бути `new`, `in progress` або `done`.
- `created_at` — дата створення у форматі ISO. Задачі без цього поля теж підтримуються: замість дати показується «—».

Щоб почати з чистого списку, заміни вміст файлу на `[]`.
